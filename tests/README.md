# 시험(테스트) 돌리는 방법

앱을 고친 뒤 예전 기능이 깨지지 않았는지 확인할 때 써요.

## 처음 한 번

```powershell
npm install
```

시험에만 쓰는 도구(jsdom, React)를 내려받아요. 앱 자체는 이 도구 없이 그대로 동작해요.

## 자동 시험: `npm test`

| 시험 | 확인하는 것 |
|---|---|
| 판정 시험 (`recognition.test.cjs`) | 한글·숫자·선·영어 **모든 글자**를 깔끔하게 / 흔들리게 / 많이 흔들리게 쓰면 통과하는지, 엉뚱한 선·빠진 획·이어 쓴 획(한글)·빠진 i·j 점은 통과하지 않는지 (약 3,500건) |
| 오프라인 시험 (`sw.test.cjs`) | 비행기 모드에서도 **가장 최근 버전**이 열리는지, 다른 페이지를 열어도 저장된 앱이 바뀌지 않는지, 예전 저장본이 정리되는지 |
| 앱 동작 시험 (`app.test.cjs`) | 시작 화면, 과목 고르기, 따라 쓰기와 "다 했어요" 안내, 펜슬 전용 모드, 펜슬 탭, 낱말 주제와 끊어 읽기, 무한 반복, 프로필·별 지우기, 설정, 영어 음성 순서 |

하나라도 실패하면 무엇이 실패했는지 보여 주고 끝나요.

## 브라우저 검사: 화면 배치와 음성 파일

진짜 브라우저가 있어야 하는 검사예요.

```powershell
npm run serve
```

브라우저에서 <http://127.0.0.1:8765/tests/browser-checks.html> 을 열고 버튼을 누르면 돼요.

- **화면 배치 검사:** 폰·태블릿·폴더블·노트북·데스크톱 17가지 크기 × 과목 4개에서, 화면 밖으로 나간 버튼 / 쓰기 칸을 가리는 버튼 / 너무 작은 버튼이 없는지 확인해요.
- **음성 파일 검사:** 앱이 말하는 문장마다 음성 파일이 있는지, 무음 파일은 없는지, 안 쓰는 파일이 남아 있지 않은지 확인해요.

## 글자나 문장을 바꿨을 때

1. `npm test`를 실행해요.
2. 말하는 문장이 바뀌었다면 음성 파일을 다시 만들어요.
   ```powershell
   node tools/make-voices.mjs build ko-KR-Chirp3-HD-Gacrux
   ```
3. 브라우저 검사의 **음성 파일 검사**를 실행해요.
